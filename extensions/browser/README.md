# Tessera 浏览器扩展：右键网页图片 → 下载到 Tessera

适用于 Chrome、Edge 等基于 Chromium 的浏览器。

## 安装（开发版，加载已解压的扩展）

1. 先运行 Tessera 应用（扩展要和它通信，应用没开时右键下载会提示“没有找到 Tessera”）。
2. 浏览器地址栏打开 `chrome://extensions`（Edge 是 `edge://extensions`）。
3. 打开右上角的“开发者模式”。
4. 点“加载已解压的扩展程序”，选择本文件夹（`extensions/browser`）。

## 使用

1. **第一次**：点一下浏览器工具栏上的 Tessera 图标（或直接右键下载一张图），Tessera 里会弹出“浏览器扩展请求连接”，点“允许”。只需要这一次。
2. 在任意网页的图片上点右键 → “下载到 Tessera”。
3. 工具栏图标上的角标表示状态：`…` 正在发送，`✓` 已发送，`!` 出错（鼠标悬停在图标上能看到原因）。下载结果会显示在 Tessera 窗口底部；窗口在后台时会弹系统通知。

## 保存到哪里

和拖拽一致：Tessera 里正停留在某个文件夹时，存到那个文件夹；否则存到你选定的下载文件夹（第一次会让你选）。

## 说明

- 只支持 `http` / `https` 的图片地址；`blob:`、`data:` 类型的图片暂不支持。
- 扩展只和本机的 127.0.0.1 通信，不会把任何内容发到网络上。
- 想撤销授权：关闭 Tessera，删除用户数据目录下 `settings.json` 里的 `bridgeTokens` 字段，再重启。

## 1.1.0：图片被透明层盖住的网站（如 Instagram）
- 新增页面脚本 `content.js`：右键时用 `document.elementsFromPoint` 找出鼠标下面的图片（`<img>`、视频封面、CSS 背景图），优先取 `srcset` 里最大的一张。
- 右键菜单改为任意位置都显示“下载到 Tessera”（以前只在浏览器认定为图片的位置显示）。
- 页面脚本需要在所有网站上运行，安装/更新时浏览器会提示“可以读取和更改所有网站上的数据”。脚本只在你右键时记下鼠标位置下的图片地址，不读取网页其他内容，也不联网。
- 更新后：在 chrome://extensions 里点“重新加载”，并刷新已打开的网页（旧标签页里还没有页面脚本）。

## 1.2.0：改名为 Tessera
- 软件和扩展统一改名为 Tessera，扩展图标也换成了新图标。
- 和应用握手时认的名字从 `shiying` 变成了 `tessera`，**扩展必须和新版 Tessera 配套使用**。
- 更新后：在 chrome://extensions 里点“重新加载”（或删除旧扩展重新加载），并刷新已打开的网页。第一次连接时 Tessera 里会再弹一次“允许”。
